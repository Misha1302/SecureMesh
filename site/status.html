Самостоятельная сборка

Для исторического main: Linux, Docker/Compose, Python, OpenSSL, .NET SDK 10.0.111, Rust 1.93.1 и закреплённый Flutter. В отдельном терминале запустите клиент после сборки и demo.

make bootstrap
bash scripts/install-flutter.sh
make build-linux
make demo
# В другом терминале:
make client

Для кандидата требования изменены: Rust 1.94.1, Flutter 3.50.0; используйте точную ревизию и соответствующее руководство. Не переносите реальный профиль без резервной копии.
