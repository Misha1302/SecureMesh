# Просмотр сохранённой переписки

Закройте SecureMesh на устройстве, с которого копируете профиль. Сохраняйте автономный зашифрованный файл `.db`, подготовленный после закрытия базы. При копировании открытой базы последние записи могут оставаться в журнале `-wal`. По одному полученному файлу невозможно определить, остался ли на исходном устройстве более свежий журнал.

1. На экране локального профиля нажмите «Посмотреть сохранённую историю».
2. Нажмите «Выбрать файл .db» и выберите копию через системное окно выбора документов. Максимальный размер снимка — 512 МиБ.
3. Введите пароль хранилища, действовавший в момент создания копии, и нажмите «Открыть для чтения».
4. Откройте переписку из списка. Доступны локально сохранённый текст, названия вложений и страницы более ранних сообщений. У старых записей может отсутствовать дата, а у переписки — сохранённое имя собеседника.
5. Вернитесь с экрана архива, чтобы закрыть просмотр. Исходный файл останется в выбранном месте.

Просмотр работает без сети. Клиент копирует зашифрованные байты во временный приватный каталог и открывает снимок SQLCipher в режиме чтения. Доступ к сообщениям ограничен содержимым снимка. Локальная очередь, идентичность MLS, серверные сеансы и привязка устройства остаются в архиве. Обмен новыми сообщениями требует отдельного входа или подключения устройства. При закрытии просмотра клиент удаляет свою временную копию. После аварийного завершения процесса зашифрованная копия может оставаться в системном временном каталоге до очистки.
