### Объединённая проверка клиента и сервера

На одном срезе прошли 46 тестов Flutter, статический анализ и восемь тестов Rust. API собрался без предупреждений. На PostgreSQL 17 прошли все 14 миграций, повторный запуск, восстановление из резервной копии и удаление синтетического аккаунта через настройки Flutter. После удаления прежняя сессия получила HTTP 401, файл локального профиля был удалён, собеседник сохранил свою историю.

В личный разговор можно добавить одно дополнительное устройство. Для добавления и отзыва используются отдельные подтверждения и смена эпохи MLS. У добавленного устройства есть доступ к новым сообщениям. Просроченная аренда пакета ключей при незавершённом переходе пока требует восстановления. Полный сценарий трёх установленных графических клиентов остаётся открытым.

В клиенте доступны голосовые сообщения, короткие видеосообщения и вызовы с явным согласием. Ранее были проверены синтетические медиаданные и локальный обмен аудио и видео между двумя WebRTC-процессами. Работа звонков через разные мобильные сети и реальные камеры и микрофоны требует отдельного испытания.
