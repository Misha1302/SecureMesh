# Локальная CLI свидетеля AKD

Сборка из корня репозитория:

```sh
cargo +1.100.0 build --locked --release --manifest-path src/key_directory/Cargo.toml --bin kt-witness
KT=src/key_directory/target/release/kt-witness
```

Каждый оператор и клиент заранее получает публичную конфигурацию и исходную контрольную точку по независимо аутентифицированному каналу. Файл `policy.txt` содержит ровно шесть разделённых пробелами или переводами строк полей: идентификатор каталога, публичный VRF-ключ каталога, четыре публичных ключа Ed25519 в порядке слотов 0–3. Каждое поле содержит 32 байта в hex. Порядок ключей входит в отпечаток политики. Файлы `old.txt` и `next.txt` содержат десятичную эпоху и корень (32 байта в hex). `advance.pb` содержит бинарное доказательство AKD для одного перехода. Лимиты чтения составляют 1024 байта для каждого текстового публичного файла и 256 КиБ для доказательства.

На машине оператора слота 0 создайте отдельный журнал по новому пути. Секретный seed Ed25519 передаётся через перенаправленный stdin: ровно 32 сырых байта. Файл seed в примере находится в распоряжении оператора.

```sh
"$KT" provision policy.txt witness.db 0 old.txt
"$KT" vote policy.txt witness.db 0 old.txt next.txt advance.pb < /run/secrets/witness-seed > vote0.txt
```

Команда записывает голос в stdout после успешной фиксации перехода. Файл голоса содержит номер слота и подпись Ed25519 (64 байта в hex). Перед передачей файла проверьте код выхода команды. Если ответ потерян, повторите тот же запрос к актуальному журналу до его следующего продвижения. Для остальных слотов используйте соответствующие ключи и собственные журналы на машинах независимых операторов. Один ключ обслуживает один актуальный журнал. Откат журнала из резервной копии или параллельный запуск того же ключа с другим журналом нарушает гарантию против подписи двух ветвей.

Клиент использует существующий профиль SQLCipher с ранее закреплёнными владельцем, VRF и checkpoint. `OWNER` ниже — идентификатор владельца профиля. Пароль передаётся как исходные байты UTF-8, включая завершающий перевод строки, если он входит в пароль.

```sh
"$KT" enroll policy.txt profile.db "$OWNER" old.txt < /run/secrets/profile-passphrase
"$KT" advance policy.txt profile.db "$OWNER" old.txt next.txt advance.pb vote0.txt vote1.txt vote2.txt < /run/secrets/profile-passphrase
```

Регистрация атомарно включает обязательный кворум для этого профиля. Для продвижения нужны три или четыре различных действительных голоса и доказательство AKD. Команда печатает `Committed` при фиксации либо `AlreadyCommitted` при точном повторе текущего перехода. Операторы и клиенты самостоятельно обеспечивают актуальность конфигурации и защиту хранилищ от отката. CLI работает с локальными файлами; доставка голосов, независимость операторов и мониторинг свежести относятся к развёртыванию.
