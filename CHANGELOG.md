# Изменения

## В разработке · кандидат для лабораторных проверок

- Переработаны список чатов, экран переписки и навигация настроек. На узком экране переписка получает отдельное окно, от 980 dp список и чат отображаются рядом. Добавлены локальные отметки непрочитанных, даты новых сообщений, выбор нескольких сообщений, избранное и закрепление на устройстве.
- Профиль собеседника показывает состояние проверки, код SHA-256 и локальный QR. Подтверждение требует совпадения введённого или считанного кода. Медиа и ссылки доступны из проверенного диалога.
- Звук и круглые видеосообщения можно воспроизводить внутри переписки. На Android добавлены нейтральные системные уведомления о сообщениях, обработанных открытым профилем в фоне.


- Открытие аккаунта и подключение устройства вынесены на первый экран. Существующие зашифрованные профили открываются через выбор профиля.
- Повторное открытие известного диалога использует ранее проверенную локальную привязку. Изменение ключа требует отдельного решения.
- У доверенного пользователя появилось отображаемое имя Unicode. В личном диалоге сохраняется отдельный username.
- Список диалогов поддерживает поиск, закрепление и обратимый архив. Клиент хранит черновики отдельно по диалогам в SQLCipher.
- Редактор поддерживает локальную разметку, выбор формата для выделения, спойлеры и копирование кода.
- Исправлено применение MLS-перехода эпохи при сохранении подтверждения отправки. Клиент различает сохранение на сервере и подтверждение обработки устройством собеседника.
- Linux-клиент поддерживает обобщённые системные уведомления в фоне для открытого диалога. Опция включается в настройках.
- Linux- и Windows-пакеты включают нативное ядро. Для Android добавлены сборка для трёх ABI и проверка подписи. Интегрирован iOS-проект ранее опубликованной alpha.
