# Физический Xiaomi, Android 15

27 ноября 2026 года на телефоне модели 24095PCADG (API 35) проверена регистрация с отображаемым именем `Z`. Собран и установлен отдельный ARM64 debug APK из исходников `baba844`. Тестовый applicationId — `com.example.securemesh_client.physicalqa27`, SHA-256 APK — `68de5e07fedf78f869a1bac2398a6989256175602311aef86bfba069ed381d89`. Сборка использовала отдельный каталог данных, временный тестовый адрес и CA только в своём процессе. Основной установленный пакет и системные настройки доверия, VPN и разблокировки сохранились.

| Этап | Фактический результат |
| --- | --- |
| Регистрация | Через форму на телефоне введены односимвольное имя, отдельный username, адрес тестового почтового ящика и единый пароль. Подтверждено сохранение пароля. Клиент перешёл к проверке почты. |
| Подтверждение и вход | Код из Mailpit введён на телефоне. Открылся экран «Чаты». PostgreSQL подтвердил сохранённое имя `Z` и верифицированный аккаунт. |
| Контакт с Linux | Независимый Linux-клиент зарегистрировался и прислал приглашение. На Xiaomi открылось окно независимой проверки ключа. Из него считан локальный отпечаток телефона, введён отпечаток непосредственно с Linux-клиента. |
| Сессия и переписка | Первый приём запроса не завершился из-за отсутствия на тестовом сервере исполняемого файла проверки MLS KeyPackage по настроенному пути. Путь исправлен. До окончания повторной проверки отпечатка телефон отключился от USB. В тестовой БД остались одно приглашение, ноль опубликованных KeyPackage, ноль созданных защищённых бесед и ноль сообщений. |

Итог по двусторонней доставке текста на этом физическом телефоне остаётся открытым. Ранее записанная проверка двустороннего обмена Android ↔ Linux проводилась на эмуляторе, и её условия приведены [в отдельном отчёте](../android-linux-recheck-20261127/interop.json).
