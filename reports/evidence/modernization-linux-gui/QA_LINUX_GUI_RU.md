# Проверка двух Linux-клиентов SecureMesh, 27 ноября 2026

Два отдельных процесса Linux x64 запущены из распакованного release bundle. Каждому выделены собственная директория профиля, Xvfb-дисплей с MIT-cookie и тестовый аккаунт. Действия выполнялись в реальных окнах через xdotool. Уведомление о регистрации получено из временного Mailpit и введено в соответствующее окно. Тестовый сервер ASP.NET Core использовал HTTPS с тестовым сертификатом и PostgreSQL. Подмены HTTP, очереди и криптобиблиотеки в этом прогоне не применялись.

Проверена пара Linux x64 на X11 с программным рендерингом. Для сетевой паузы применялись SIGSTOP/SIGCONT к одноразовому API. Она проверяет недоступность сервиса, а замеры пропускной способности и задержки 2G требуют отдельного прогона. Установщик, физические мобильные устройства, Fedora/Wayland, независимый криптографический аудит и уведомления рабочего стола в этот сценарий не входили.
